# 026b-19 — Device calibration factor
**Epic:** 026b-Reference-device-and-porting-guide · **Effort:** S · **Depends on:** 026b-09, 026a-11, epics 024, 025

## Context

Module code on the device is generated by the DSL compiler (epic 024). The compiler's cost bound is counted in **abstract operations per slice, identical on every machine**. Each target has a **calibration factor (time per operation), measured once and recorded in the regime stamp**; admission converts the cost bound with it (C-106).

The procedure is settled (C-176): the DSL conformance suite (epic 025) runs a reference workload once per listed target and records time per operation; the value is carried in the regime stamp. The reference device is a new target, so this epic lists it with epic 025, provides the on-board runner for the suite's workload, and stamps the value. Slices are 0.5 ms (C-02) at 2 000 per second; the device's CPU is shared with the resampler (026b-05) and the cooperative `poll` loop (026b-06).

The device stamp is published in sections, multicast on change and every 10 s (C-18).

## Work

1. Register the reference board as a listed target of epic 025's conformance suite and run the suite's reference workload (C-176) on the board, linked as in 026b-09, and measure time per abstract operation with the cycle counter.
2. Record the factor in the firmware profile so it is published in the stamp (a stamp field defined by epic 013 / 024; if missing, add it per 013's extension rule or record the gap with owner epic 013).
3. Record the measurement in `doc/design/reports/` (C-130); the measurement program is a tool binary or probe as C-133 places it.

## Acceptance criteria

1. Calibration factor recorded `[measured]` with the workload, compiler version and firmware version.
2. The stamp recorded by the hosted collector shows the factor.
3. For the exact-fixed module of 026b-09, the compiler's operation count times the factor predicts the measured time per slice; the prediction error is recorded.
4. Firmware still passes the no-alloc / no-libm check.
